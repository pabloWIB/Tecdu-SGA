## 📌 Descripción del Proyecto

**Tecdu-SGA** es una propuesta de rediseño visual y estructural de la plataforma académica **Tecdu-SGA**. Este repositorio contiene los distintos módulos que conforman la interfaz de usuario reconstruida, con enfoque en mejorar la experiencia de navegación, claridad visual y usabilidad para estudiantes, administrativos y docentes.

---

## 🚀 Características Principales

- ✨ Interfaz moderna, minimalista y responsive  
- 🎓 Módulos separados  
- 📁 Estructura clara por carpetas
- 🎯 Navegación intuitiva y mejoras en UX/UI  
- 💡 Integración visual de Figma al desarrollo real

## 🔑 Componentes Clave

- **Navbar Modular**: Estructura adaptable para todos los módulos
- **Panel de usuario**: Vista personalizada por tipo de usuario (docente, estudiante, admin)
- **Tablas dinámicas**: Datos organizados y responsivos
- **Formulario UI mejorado**: Inputs más claros y validación nativa
- **Animaciones suaves**: Mejor experiencia de uso sin sobrecargar

## 🧪 ¿Cómo iniciar el proyecto?

1. Clona el repositorio:
   ```bash
   git clone https://github.com/pabloWIB/Tecdu-SGA.git

2. Abre la carpeta en tu editor (VS Code recomendado).

3. Explora y modifica los archivos `index.html`, `css/styles.scss` y `js/script.js` según sea necesario.

4. Visualiza el proyecto abriendo `index.html` en tu navegador.
